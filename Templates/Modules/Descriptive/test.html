🎭 Declensions Module

Система управления склонениями и синонимами для текстовых шаблонов

📖 Документация

Описание модуля

Declensions (Склонения) — это модуль для работы с текстовыми шаблонами, где нужно вставлять одни и те же слова в различных формах (падежах, склонениях). Например, вам нужно подставить прилагательное "красивый" в разных падежах:
красивый (именительный), красивого (родительный), красивому (дательный) и т.д.

Основные компоненты

1. Класс Declensions (Контейнер склонений)

Главный класс для управления всеми склонениями.

  • createDeclension(name, types) — создать новое склонение с указанными типами
  • getDeclension(name) — получить объект склонения
  • removeDeclension(name) — удалить склонение
  • toJSON() — экспортировать все склонения в JSON
  • fromJSON(json) — импортировать склонения из JSON

2. Класс Declension (Одно склонение)

Работает с одним набором синонимов/форм.

  • addSynonyms(type, synonyms) — добавить синонимы для определённого типа
  • getSynonyms(type) — получить все синонимы для типа
  • getRandom(type) — получить случайный синоним
  • removeSynonyms(type, synonym) — удалить конкретный синоним
  • removeAllSynonyms(type) — очистить все синонимы типа
  • clear() — полностью очистить склонение
💡 Совет: "Типы" (types) — это любые метки/категории для группировки синонимов. Например, для прилагательного "красивый" типы могут быть: "nominative" (именительный), "genitive" (родительный), "dative" (дательный) и т.д.

📚 Примеры использования

Пример 1: Работа с прилагательным

// Создаём контейнер const declensions = new Declensions(); // Создаём склонение для прилагательного "красивый" declensions.createDeclension('beautiful', ['nominative', 'genitive', 'dative']); // Получаем объект const beautifulAdj = declensions.getDeclension('beautiful'); // Добавляем формы beautifulAdj.addSynonyms('nominative', ['красивый', 'прекрасный']); beautifulAdj.addSynonyms('genitive', ['красивого', 'прекрасного']); beautifulAdj.addSynonyms('dative', ['красивому', 'прекрасному']); // Используем console.log(beautifulAdj.getRandom('nominative')); // красивый или прекрасный console.log(beautifulAdj.getSynonyms('genitive')); // ['красивого', 'прекрасного']

Пример 2: Работа с существительным

declensions.createDeclension('cat', ['nominative', 'genitive', 'dative']); const catNoun = declensions.getDeclension('cat'); catNoun.addSynonyms('nominative', ['кот', 'кошка', 'кошечка']); catNoun.addSynonyms('genitive', ['кота', 'кошки', 'кошечки']); catNoun.addSynonyms('dative', ['коту', 'кошке', 'кошечке']); // Используем в тексте console.log(`Я вижу ${catNoun.getRandom('nominative')}`); // "Я вижу кошечка" или "Я вижу кот" и т.д.

Пример 3: Сохранение и загрузка

// Сохраняем в JSON const jsonData = declensions.toJSON(); localStorage.setItem('declensions', JSON.stringify(jsonData)); // Загружаем из JSON const loadedDeclensions = new Declensions(); const savedData = JSON.parse(localStorage.getItem('declensions')); loadedDeclensions.fromJSON(savedData);

Практический пример: Генератор текста

const declensions = new Declensions(); // Подготавливаем данные declensions.createDeclension('hero', ['nominative', 'genitive']); const heroAdj = declensions.getDeclension('hero'); heroAdj.addSynonyms('nominative', ['героический', 'отважный', 'смелый']); heroAdj.addSynonyms('genitive', ['героического', 'отважного', 'смелого']); // Генерируем текст function generateText() { const adjNom = heroAdj.getRandom('nominative'); const adjGen = heroAdj.getRandom('genitive'); return `${adjNom} боец готов к бою ${adjGen} врага.`; } console.log(generateText()); // "отважный боец готов к бою смелого врага."
Метод Параметры Возвращает Описание
addSynonyms type, synonyms[] — Добавляет синонимы для типа
getSynonyms type string[] Возвращает массив синонимов
getRandom type string Возвращает случайный синоним
removeSynonyms type, synonym — Удаляет конкретный синоним

⚠️ Обработка ошибок

Модуль выбросит ошибку в следующих случаях:

  • Дублирование имени: Если попытаетесь создать склонение с уже существующим именем
  • Несуществующее склонение: Если попытаетесь получить/удалить несуществующее склонение
  • Неверный тип: Если попытаетесь добавить синонимы для типа, который не был указан при создании
  • Пустой список: Если попытаетесь получить случайный синоним из пустого списка
  • Синоним не найден: Если попытаетесь удалить несуществующий синоним

Обработка исключений

try { declensions.createDeclension('duplicate', ['type1']); declensions.createDeclension('duplicate', ['type2']); // Ошибка! } catch (error) { console.error('Ошибка:', error.message); // "Declension with name duplicate already exists." } try { const nonexistent = declensions.getDeclension('unknown'); // Ошибка! } catch (error) { console.error('Ошибка:', error.message); // "Declension with name unknown does not exist." }
